Практико-ориентированная проектная работа по разработке программного продукта на языке Python с использованием технологий распознавания речи, обработки голосовых команд, получения данных из сети Интернет и воспроизведения ответов собственным голосом автора.

Суть проекта

Что вы делаете

01

Разрабатываете собственного помощника

Программу, которая воспринимает голосовые команды пользователя через микрофон, распознаёт их, определяет необходимое действие и выполняет его.

Персонализируете его

Для формирования голосовых ответов необходимо использовать собственный голос автора проекта: самостоятельно записать необходимые слова, числа и фразы и подготовить их для использования программой.

В ходе работы необходимо

  • изучить общий принцип работы голосовых помощников;
  • разобраться, каким образом компьютер получает и распознаёт речевую информацию;
  • записать набор слов и фраз собственным голосом;
  • разработать программу на языке Python;
  • реализовать распознавание голосовых команд.
  • реализовать выполнение предусмотренных командами действий;
  • организовать формирование ответов из собственных голосовых записей;
  • получить и обработать данные о погоде из интернет-сервиса;
  • протестировать работу созданного помощника;
  • определить возникающие ошибки и ограничения программы.

Минимальный функционал

Что помощник обязан уметь

03
1

Сообщать текущее время

Время определяется автоматически по системным данным компьютера и озвучивается голосом автора проекта.

2

Сообщать текущую дату

Дата определяется автоматически и используется для формирования голосового ответа.

3

Сообщать текущую погоду

Необходимо автоматически получать актуальные данные из интернет-сервиса. Помощник должен сообщать как минимум температуру воздуха и состояние погоды (дождь, снег, облачно, ясно).

4

Запускать таймер

Пользователь задаёт продолжительность таймера голосовой командой. После истечения указанного времени программа сообщает о завершении отсчёта.

Дополнительные функции

Дополнительно могут быть реализованы другие функции: запуск программ на компьютере, выполнение простых вычислений, открытие сайтов, создание заметок, воспроизведение звуков, дополнительные информационные команды и др.

Персонализация

04

Учащийся самостоятельно

  • записывает свой голос;
  • определяет, какие слова и фразы потребуются программе;
  • сохраняет и организует аудиофайлы;
  • использует записанные фрагменты для формирования ответов помощника.

Ответ собирается из фрагментов

Допускается формирование одной фразы из нескольких записанных элементов.

«Сейчас» + «двадцать» + «один» + «тридцать» + «пять»
Все голосовые ответы помощника должны формироваться с использованием аудиофрагментов, записанных собственным голосом автора проекта.

Пояснительная записка

Структура индивидуального проекта

08

1. Актуальность

Обоснуйте актуальность разработки голосового помощника и использования голосового управления.

При подготовке раздела подумайте:

  • где сегодня применяется голосовое управление;
  • чем голосовой способ взаимодействия отличается от управления с помощью клавиатуры и мыши;
  • в каких ситуациях голосовое управление может быть удобным;
  • почему разработка и изучение подобных систем представляет интерес.
Актуальность необходимо сформулировать самостоятельно, применительно к разрабатываемому проекту.

2. Цель проекта

Разработать персонализированный голосовой помощник на языке Python, способный распознавать голосовые команды пользователя, выполнять заданные действия и предоставлять ответы с использованием голоса пользователя.

3. Задачи проекта

  1. Изучить принципы работы голосовых помощников и способы распознавания голосовых команд.
  2. Определить структуру, основные функции и набор команд персонализированного голосового помощника.
  3. Реализовать распознавание и обработку голосовых команд на языке Python.
  4. Реализовать основные функции помощника: сообщение текущего времени и даты, получение информации о погоде и установку таймера.
  5. Создать набор персонализированных голосовых ответов с использованием записей голоса пользователя.
  6. Объединить распознавание команд, выполнение функций и голосовые ответы в единую программу.
  7. Провести тестирование разработанного голосового помощника и оценить корректность выполнения команд.
  8. Выявить ограничения разработанного решения и определить возможные направления его дальнейшего развития.

4. Методы исследования и разработки

При выполнении проекта необходимо выбрать только те методы, которые действительно используются в вашей работе. Использовать все перечисленные методы не требуется.

Выбранные методы необходимо конкретизировать применительно к своему проекту: указать не только название метода, но и пояснить, для чего и каким образом он использовался в работе.

Например, недостаточно указать только «эксперимент» — необходимо пояснить, какой эксперимент был проведён и с какой целью.

Наблюдение
активный познавательный процесс, опирающийся, прежде всего, на работу органов чувств человека и его предметную материальную деятельность. Осуществляется планомерно, целенаправленно, активно, систематично.
Эксперимент
метод познания, предполагающий целенаправленное изменение объекта для получения знаний, которые невозможно выявить в результате наблюдения.
Измерение
процедура определения численного значения величины посредством единицы измерения. Ценность этого метода заключается в том, что он дает точные, количественно определенные сведения об окружающем мире.
Моделирование
метод исследования объектов познания на их моделях; построение и изучение моделей реально существующих предметов и явлений и конструируемых объектов для определения либо улучшения их характеристик, рационализации способов их построения, управления ими и т. п.
Сравнение
один из наиболее распространённых методов познания. Сравнение позволяет установить сходство и различие предметов и явлений. Выявление общего, повторяющегося в явлениях — это серьёзный шаг к познанию закономерностей и законов окружающего нас мира.
Анализ
заключается в разложении изучаемого на единицы и раздельном изучении этих частей как элементов целого.
Синтез
играет ведущую роль в исследовании, так как позволяет соединить части в целое, воссоздать из разрозненных частей нечто новое, единое, взаимодействующее с составными частями.

5. Основная часть

1. Теоретический раздел

Определите, какие теоретические сведения необходимы для понимания принципа работы созданного голосового помощника.

Теоретическая часть должна быть непосредственно связана с практической разработкой и не должна представлять собой общий реферат о голосовых помощниках.

2. Проектировочный раздел

Опишите разработанную вами концепцию голосового помощника:

  • какие функции было решено реализовать;
  • какие голосовые команды используются;
  • какие программные средства были выбраны;
  • как организована персонализированная озвучка;
  • по какому алгоритму обрабатывается голосовая команда.

Обоснуйте принятые решения.

 

3. Практический раздел

Опишите процесс создания собственного программного продукта. Покажите основные этапы разработки и объясните назначение наиболее важных компонентов программы.

Не следует помещать в презентацию весь исходный код программы.

4. Тестирование

Самостоятельно разработайте способ проверки созданного голосового помощника.

Проверьте работу всех реализованных функций, зафиксируйте результаты и проанализируйте обнаруженные ошибки или ограничения.

По результатам тестирования сделайте вывод о работоспособности созданного продукта.

6. Заключение

Самостоятельно подведите итоги выполненной работы.

Соотнесите полученный результат с поставленной целью и задачами, оцените результат разработки, укажите выявленные ограничения и возможные направления дальнейшего развития голосового помощника.

Заключение не должно содержать новую теоретическую информацию.

7. Список источников

Укажите фактически использованные при выполнении проекта источники: учебные и справочные материалы, документацию языка программирования и библиотек, материалы по распознаванию речи, документацию интернет-сервисов и другие использованные ресурсы.

Финальный ориентир

Помощник должен не просто работать — вы должны понимать, как он работает.
